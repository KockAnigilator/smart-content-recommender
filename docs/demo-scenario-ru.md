# Сценарий демонстрации (5-7 минут)

## 1) Вступление (30-40 сек)
- Тема: система рекомендаций контента на основе поведения пользователей.
- Архитектура: Clean Architecture, ASP.NET Core Web API, PostgreSQL, WPF.
- Поддержаны роли `Admin` и `User`.

## 2) Запуск проекта (40-60 сек)
- Запустить скрипт:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\run-demo.ps1
```

- Показать, что открылись API и WPF клиент.
- Открыть Swagger: `http://localhost:5078/swagger`.

## 3) Пользовательский сценарий (2-3 минуты)
- В WPF войти под `user1@local / User123!`.
- Загрузить контент.
- Выбрать 2-3 записи и выполнить действия `View`, `Like`, `Click`.
- Перейти в рекомендации:
  - `Popular`
  - `By Categories`
  - `KNN`
- Пояснить, что рекомендации перестраиваются по истории действий.

## 4) Админский сценарий (1-2 минуты)
- Войти под `admin@local / Admin123!`.
- Открыть админ-вкладку пользователей.
- Изменить роль пользователя.
- Заблокировать пользователя.
- Показать, что заблокированный пользователь больше не может войти.

## 5) Завершение (30-40 сек)
- Показать структуру проекта в solution.
- Показать `docs/architecture.md` (диаграммы).
- Кратко отметить, что есть демо-разделение на микросервисы:
  `AuthService`, `ContentService`, `RecommendationService`.
